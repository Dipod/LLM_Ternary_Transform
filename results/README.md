# Phase 0 results

Recorded Phase 0 runs live here, one directory per experiment id, and are
git-ignored except this file (`.gitignore` -> `results/*`). Each run directory
contains `config.yaml`, `metrics.json` and `report.md`
(`.kilo/rules/research-discipline.md`).

Run the reduced sweep from the repository root with:

```
.venv\Scripts\python.exe -m phase0_feasibility.main
```
